# Security Policy

This is an academic research repository associated with a peer-reviewed publication. It does not operate any production services or user-facing infrastructure.

## Reporting a Vulnerability

If you discover a security issue — such as an exposed credential, a vulnerable dependency, or malicious code — please **do not open a public issue**. Instead, report it privately:

- **Email:** [esertel@ucla.edu](mailto:esertel@ucla.edu)

We will acknowledge your report within **5 business days**.

## Credentials

This repository does not contain any API keys, OAuth tokens, or service account credentials. Google Earth Engine authentication is handled locally via `earthengine authenticate` and must not be committed to this repository under any circumstances.

## Supported Versions

Security fixes are applied to the `main` branch only.
